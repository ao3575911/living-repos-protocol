# Living Repositories Protocol

A manifest that declares what a repository's cloud agent may do, how it is isolated and where it reports state.

- [Specification](spec.md): every field, its rules and validation modes.
- [Schema reference](schema-reference.md): field table generated from the schema.
- [Runtime capability document](runtime.md): how a runtime declares what it supports, and how a manifest is matched against it.
- [Versioning](versioning.md): protocol versions, releases and what counts as breaking.
- [Protocol PRD](protocol-prd.md): problem, users and scope.
- Raw schemas: [strict](https://ao3575911.github.io/living-repos-protocol/schemas/manifest.schema.json), [lenient (v0.1.0 rules)](https://ao3575911.github.io/living-repos-protocol/schemas/manifest.lenient.schema.json), [runtime document](https://ao3575911.github.io/living-repos-protocol/schemas/runtime.schema.json).

Source and issues: [github.com/ao3575911/living-repos-protocol](https://github.com/ao3575911/living-repos-protocol). Examples: [Living Repositories guide](https://ao3575911.github.io/living-repos/).
